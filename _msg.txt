v1.3.10 网页/APK 体验修复 + 公式集返回栈与小节导航

【用户反馈的四项】
1. 网页与 APK 每个页签顶部都有「关于本页」，刷屏影响阅读
   → 全部移除，只在公式集页末尾保留一处（build-www.js 的 insertPubnote）
2. 正文里大量 **加粗** 标记被原样输出成字面量 **
   → 新建两端共用 miniprogram/utils/inline-md.js（parseInline / inlineHtml）
     小程序端按片段切 <text> 渲染，网页端包 <b>；只处理成对 **，不误伤数学乘号
3. 公式集里点返回直接退出页面/APP，而不是返回上一页
   → 根因：单页应用从不写 history，WebView.canGoBack() 恒为 false
     改为用 location.hash 记录视图（#/calc/xxx），返回时 history.back()
     file:// 下 pushState 会抛 SecurityError，故用 hash
     popView() 先同步还原界面再后退，按钮路径与系统返回键行为一致
4. 公式集点进去的长条目没有小节导航
   → 45 个评估条目全部含 ≥2 个小节，全部加上胶囊式小节导航 + 锚点跳转

【构建链路修复】
- build-apk.bat 的「复制 APK 到仓库根目录」段改由 android-app/finalize-apk.js 承担
  原因：cmd 的 copy + for /f + dir + del 在 Git Bash 驱动下不稳定
  （两次运行报不同错误，且 copy 会吞掉目标名的 .apk 扩展名）
- 构建产物根目录固定为 EchoRef-v<版本>.apk，并自动清理旧版本
