二、新增判读条目「超声伪影识别与规避（2026 ASE 指南）」（44 个 block / 7 节）
- 分类框架：按「被打破的机器假设」归类，而非按伪影名称
- 轴向伪影：简单混响、升主动脉混响（44–55% 的检查都有，最易误判为 A 型夹层）、
  复杂混响彗星尾、镜像、声影与增强、速度位移（脂肪房间隔）
- 侧向伪影：折射、波束宽度、侧瓣（三条识别特征）
- 多普勒伪影：overgain / undergain / 壁滤波 150 Hz vs 350 Hz /
  混叠（Nyquist = PRF/2）/ 镜像频谱 / 频谱增宽
- 彩色多普勒三坑：侧瓣 color splay、blooming、twinkling
- 3D 与造影特有伪影：stitching / dropout / 模糊 / 衰减 / swirling
- 收尾「看到什么 → 先想哪个伪影 → 怎么验证」速查表
- 判读页分入新分组「伪影识别与规避」（插在 intervention 与 report 之间）
