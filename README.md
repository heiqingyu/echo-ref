## 二、功能说明

小程序分四个 Tab 页，数据通过全局状态联动。

### Tab 1 · 基本参数

- 输入身高、体重 → 自动算 BSA
- 切换性别（男/女）
- 切换 BSA 公式：**Du Bois**（默认，临床试验通用）/ **Mosteller**（口算便捷）
- 切换参考标准：**中国成人标准**（默认）/ **ASE 国际标准**

### Tab 2 · 参考值

- 依据性别 + 参考标准展示 20（CN）/ 22（ASE）项参数的正常范围
- **若在 Tab 3 计算过**，会自动显示实测值与参考范围的对照，并标注 ↑偏高 / ↓偏低 / 正常

### Tab 3 · EF 计算

输入 4 个测量值（单位 mm）：

| 参数 | 含义 |
|---|---|
| LVIDd | 左室舒张末期内径 |
| LVIDs | 左室收缩末期内径 |
| IVSd | 室间隔舒张末期厚度 |
| LVPWd | 左室后壁舒张末期厚度 |

输出：

- **容积指标**：EDV、ESV、SV
- **收缩功能**：EF（含彩色分级进度条）、FS、RWT
- **左室质量**：LVM、LVM/BSA

### Tab 4 · 儿童 Z 值（0–18 岁）

儿童心脏随生长剧烈变化，**固定区间必然失真**（新生儿 LVEDD 2 cm 正常，
成人 2 cm 是严重缩小）。国际上把测值按体表面积标准化后算 **Z 值**：

- 输入身高体重 → 自动按 **Haycock 公式**算 BSA
- 填测量值（内径 mm / 容积 mL / 质量 g / 面积 cm²），常用 8 项快捷输入，
  展开可填全部 **33 项**
- 输出每项的 **Z 值 + 判定**，以及 **±2SD / ±3SD** 对应的实测区间
- 结果摘要：正常 / 轻度 / 显著 各几项，并指出偏离最大的项

**判定阈值**：|Z| ≤ 2 正常；2 < |Z| ≤ 3 轻度异常；|Z| > 3 显著异常。

> ⚠️ 本页 **不区分性别**。PHN 研究结论：Z 值受年龄、性别、种族影响
> 在统计上显著，但差异 < 5%，低于测量者间变异，**临床上可忽略**。

## 三、计算公式

### 体表面积

```
Du Bois  ：BSA = 0.007184 × 身高^0.725 × 体重^0.425
Mosteller：BSA = √(身高 × 体重 ÷ 3600)
```

### Teichholz 法（M 型单平面）

```
V = 7 × D³ ÷ (2.4 + D)        D 单位 cm，V 单位 mL
EF = (EDV − ESV) ÷ EDV × 100%
FS = (LVIDd − LVIDs) ÷ LVIDd × 100%
```

### 左室质量（Devereux 公式）

```
LVM(g) = 0.8 × 1.04 × [(LVIDd + IVSd + LVPWd)³ − LVIDd³] + 0.6
RWT    = 2 × LVPWd ÷ LVEDD
```

> ⚠️ **精度约定**：LVM 先舍入到 1 位小数，再计算 LVM/BSA 指数。
> 这样「用户拿界面显示的数字手算」与「程序输出」完全一致，避免临床核对时产生困惑。

### 儿童 Z 值

```
体表面积（Haycock，儿科首选）
  BSA(m²) = 0.024265 × 身高(cm)^0.3964 × 体重(kg)^0.5378

Z 值
  Z = ( 实测值 ÷ BSA^α − Mean ) ÷ SD

其中 α / Mean / SD 是每个参数各自的回归系数。
Z = 0 即人群均值；|Z| ≤ 2 覆盖约 95% 健康儿童。
```

**等价变形**：`Z = (实测值 − Mean×BSA^α) ÷ (SD×BSA^α)`，两种写法数学等价，
程序采用前一种（先指数化再比较），与 PHN 原文公式一致。

**为什么不用「年龄」？** 因为 cardiovascular 结构与 **BSA** 的相关性远强于年龄。
PHN 用 3566 例样本验证过：按 BSA 标准化后，年龄的额外影响在临床上可忽略。
换句话说 —— **同龄孩子体型差异大时，心脏大小差异主要由体型决定，而非年龄。**
所以本页只需要身高体重，**不需要精确年龄**（年龄栏仅用于越界提醒）。

## 四、参考值来源

### 中国成人标准（默认）

中华医学会超声医学分会《中国成人超声心动图正常参考值》，样本量 n=678，18~59 岁，95% 参考范围。

覆盖 20 项参数：LA-ap、LA-l、LVOT、IVSd、LVPWd、LVEDD、LVESD、LVEDV、LVESV、LVEF、LVM、LVM/BSA、LVM/H2.7、LVEDD/H、LVRWT、RA-l、RA-t、RV-ap、RV-l、RVOT。

### ASE 国际标准

ASE/EACVI 2015《Recommendations for Cardiac Chamber Quantification in Adults》。

采用**分区值**（正常 / 轻度异常 / 中度异常 / 重度异常），覆盖 **22 项**参数：

| 分组 | 参数 |
|---|---|
| 左室结构 | LVEDD、LVEDD/BSA、LVEDD/H、IVSd、LVPWd |
| 左室容积与质量 | LVEDV、LVEDV/BSA、LVESV、LVESV/BSA、LVM、LVM/BSA |
| 左室收缩功能 | EF、FS |
| 左房 | LA-ap、LAV、LAV/BSA |
| 右心 | RV-ap、RVOT-plax、RA-l、RA-t、TAPSE |
| 下腔静脉 | IVC-d |

#### ⚠️ 单位换算（重要）

ASE 指南原文中，**内径类参数以 cm 表示**（如 LVEDD 男性正常 4.2–5.9 cm），
而本小程序界面统一使用 **mm**。

如果直接把用户输入的 `50`（mm）与 `5.9`（cm）比较，会**误判为"重度异常"**。

**解决方案**：数据表中通过 `PARAM_UNIT_ASE` 显式声明每个参数的**原生单位**，
再由 `buildReferenceList` 中的 `convertUnit` / `convertPartition` 自动换算：

```
ASE 原生 (cm)  →  ×10  →  界面单位 (mm)
LVEDD 正常 4.2–5.9 cm  →  42–59 mm
IVSd  正常 0.6–1.0 cm  →  6–10 mm
```

容积类（mL）、质量类（g）、分数类（%）单位一致，**不做换算**。
比值类（cm/m²、mL/m² 等）保持原值。

> 这个换算层是修复「切到 ASE 标准后正常值被显示成重度异常」的关键。
> 回归测试中已锁定该行为（`verify-mp.js` 第 9、10、12、13 节）。

#### BSA 联动：指数参数反算绝对范围

指数类参数（如 `LVEDD/BSA`）的参考值是**固定的指数区间**（2.2–3.1 cm/m²），
本身与 BSA 无关。但临床上更关心「**以我的体型，内径多大算正常**」。

因此程序会按 `指数 × BSA` **反算出绝对范围**一并显示：

| BSA | 指数范围（固定） | 折算内径（随 BSA 变） |
|---|---|---|
| 1.50 | 2.20–3.10 cm/m² | **33–47 mm** |
| 1.75 | 2.20–3.10 cm/m² | **39–54 mm** |
| 2.00 | 2.20–3.10 cm/m² | **44–62 mm** |

**共 5 个参数参与联动**（定义在 `BSA_INDEX_MAP`）：

| 参数 | 反算目标 | 折算单位 |
|---|---|---|
| LVEDD/BSA | LVEDD | mm |
| LVEDV/BSA | LVEDV | mL |
| LVESV/BSA | LVESV | mL |
| LVM/BSA | LVM | g |
| LAV/BSA | LAV | mL |

**不参与联动**（设计如此，符合指南规范）：

- **绝对值类**：LVEDD、IVSd、LVPWd、LA-ap、LVEDV、LVESV、LVM、LAV、RV-ap 等
  —— ASE/CN 给的就是不分体型的绝对区间，标准化另由指数参数承担
- **比值/百分数类**：EF、FS、RWT、LVEDD/H
  —— 本身已归一化，与 BSA 无关

> CN 标准下的 `LVM/BSA`（44.3–108.5 g/m²）同样参与联动。

**注意**：ASE 表中 EF 的键名是 `EF`（不是 `LVEF`），CN 表中是 `LVEF`。
这是两套标准的原生字段名差异，代码中已正确处理，实测值字典两个键都会填。

### 儿童 Z 值标准（Tab 4）

**Pediatric Heart Network（PHN）Normal Echocardiogram Database**

- 主文献：Lopez L, Colan S, et al. *Circ Cardiovasc Imaging.* 2017;10(11):e006979.
- 样本：**n = 3566**，0–18 岁健康非肥胖儿童，19 个中心，Core Lab 统一测量
- 系数表公开：https://www.pediatricheartnetwork.org/forresearchers/echo-z-scores/
- 同源前身：Pettersen MD, et al. *JASE* 2008;21(8):922-934（波士顿儿童医院 Z 值系统基于此）

**LVESD / LVESV 的系数**来自该数据库的后续补充发表
（*"PHN Echocardiographic Z-Scores: Comparison to Other Published Models"*, PMC7870534），
因为这两项未包含在首发的索引表中：

| 参数 | α | Mean | SD |
|---|---|---|---|
| LVESD | 0.5 | 2.675 | 0.352 |
| LVESV | 1.3 | 25.76 | 5.551 |

覆盖 **33 项**参数，分 9 组：

| 分组 | 参数 |
|---|---|
| 左心室结构 | LVEDD、LVESD、LVST、LVPWT |
| 左心室容积与质量 | LVEDV、LVESV、LVM |
| 左心室长径与面积 | LVEDL、LVEDA |
| 主动脉 | ANN、ROOT、STJ、AAO、ARCHP、ARCHD、ISTH |
| 冠状动脉 | LMCA、LAD、RCA |
| 肺动脉 | PVSAX、PVLAX、MPA、RPA、LPA |
| 二尖瓣 | MVAP、MVLAT、MVA |
| 三尖瓣 | TVAP、TVLAT、TVA |
| 形态比例 | LVMTV、LVTTD、LVSI |

#### ✅ 交叉验证（重要）

PHN 系数在**成人 BSA** 下的推算值，应与 **ASE 成人正常范围**吻合 ——
这是验证公式与系数正确性的独立手段：

| 项目 | PHN 推算（BSA=1.847） | ASE 成人指南 |
|---|---|---|
| LVEDD 均值 | 5.13 cm | — |
| LVEDD ±2SD | **4.26 – 6.00 cm** | **4.2 – 5.9 cm** |

两者高度吻合，说明公式与系数自洽，且在儿科范围外推时仍然合理。
该交叉验证已写入 `verify-peds.js` 第 10 节与 `verify-project.js` 第 9.7 节。

#### 单位约定

PHN 原生单位：内径 **cm**、容积 **cm³(mL)**、质量 **g**、面积 **cm²**。
界面统一为 **mm / mL / g / cm²**，因此**长度类在算 Z 前必须 ÷10**。

> 若漏掉这一步，`38 mm` 会被当成 `38 cm`，Z 值直接飞到 ~100。

## 八、修改数据后必须做的事

改完 `echo-core.js` 或 `peds-zscore.js` 后，跑一遍：

```bash
node verify-project.js && node verify-mp.js && node verify-peds.js
```

三套全绿才算改对。

### 历史踩坑记录

1. **期望值凭直觉填** —— 曾因手工估算导致 3 + 2 个"假失败"
   （如 Teichholz D=5.0cm 应为 118.24 而非 125；ASE 男性 LVEDV=190 本就该判中度）。
   → **期望值必须独立手算或查数据表复核。**

2. **ASE 表单位错配** —— ASE 原生单位是 cm，界面是 mm，直接比较导致
   LVEDD=50mm 被误判"重度异常"。
   → 已引入 `PARAM_UNIT_ASE` + `convertUnit` 换算层，并加回归测试锁定。

3. **双份引擎不同步** —— 早期同时维护 ES Module 和 CommonJS 两份实现，
   ASE 表扩充后两边不一致。
   → 已合并为单一数据源。

4. **`miniprogramRoot` 漏配** —— 代码放在 `miniprogram/` 子目录但未在
   `project.config.json` 声明，导致开发者工具报「未找到 app.json」。
   → 已补上该字段。

5. **BSA 未参与参考值计算** —— 用户发现切换 BSA 时参考范围纹丝不动。
   根因是指数类参数的参考范围直接查表显示，缺少「按 BSA 反算绝对值」这一步。
   → 已引入 `BSA_INDEX_MAP` + `deriveAbsoluteRange`，5 个指数参数实现联动。

6. **儿童系数凭印象填错** —— 写 `peds-zscore.js` 时，LVESD/LVESV 的系数
   在 PHN 首发索引表中**没有**，我最初按相邻参数"推测"填了 2.36 / 25.07。
   核对补充文献后发现正确值是 **2.675 / 25.76**。
   → **凡是数据表里没有的值，必须查到出处，不能推测。**
   已在 `verify-peds.js` 第 6 节加回归测试锁定这两项。

7. **测试里的"参数总数"写错** —— 我在测试中写"34 项"，实际表里是 33 项，
   导致 5 个假失败。**表是手写的，数是数出来的，别凭感觉写常量。**

## 十一、常见问题

**Q：儿童页为什么要填身高体重，不能直接填年龄吗？**
A：因为心脏大小与 **体表面积（BSA）**的相关性远强于年龄。
同为 5 岁，一个 15 kg 一个 25 kg，心脏大小差异主要由体型决定。
PHN 已用 3566 例验证：按 BSA 标准化后，年龄的额外影响临床上可忽略。
年龄栏仅用于「超过 18 岁提醒你用成人标准」这一提示。

**Q：儿童页为什么不分性别？**
A：PHN 研究结论 —— 性别对 Z 值的影响统计上显著但 < 5%，
低于测量者间变异（≥5%），临床上可忽略。所以一套系数通用。

**Q：Z 值 2.5 算严重吗？**
A：|Z| 在 2–3 之间属**轻度异常**，3 以上才是**显著异常**。
但 Z 值只是判读工具之一，是否干预取决于结构类型、趋势变化和临床症状。

**Q：切到 ASE 标准后单位对不上？**
A：已修复。指南原文用 cm，界面用 mm，程序会自动换算。
如果你看到参考区间显示成 `42.0–59.0 mm` 这样，就是对的。

**Q：体验版到期了怎么办？**
A：15 天有效期。到期后到 mp.weixin.qq.com →「管理」→「版本管理」，
重新点一次「选为体验版本」即可，无需重新上传。

**Q：想装到安卓手机当 App 用？**
A：微信里「添加到桌面」即可当独立图标用。
若要真正的 APK，需要 WebView 壳（Capacitor / Cordova）把网页版打包，
但本工具定位就是微信小程序 + 体验版，0 成本，够用。
