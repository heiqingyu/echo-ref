# 心脏超声参考值速查

个人整理的**成人经胸超声（TTE）参考值速查工具**，用于把常见测量值快速对照正常范围、
算清射血分数和左室质量、以及按体表面积标准化查看儿童心脏结构。

**本页内容为自行整理，非任何学会或机构的官方产品**，仅供医学教育与速查使用。

## 一、功能

### 1. 参数 · 参考值

- 输入身高体重 → 自动算 **体表面积（BSA）**
- 切换性别（男 / 女）
- 切换 BSA 公式：**Du Bois**（默认，临床试验通用）/ **Mosteller**（口算便捷）
- 切换参考标准：**中国成人标准**（默认）/ **ASE 国际标准**
- 展示各参数的正常参考范围；若已录入测量值，会**自动对照并标注 ↑偏高 / ↓偏低 / 正常**

**参考值来源**

| 标准 | 出处 | 覆盖 |
|---|---|---|
| 中国成人标准 | 中华医学会超声医学分会《中国成人超声心动图正常参考值》 | 37 项，18–59 岁，95% 参考范围 |
| ASE 国际标准 | ASE/EACVI 2015《Recommendations for Cardiac Chamber Quantification in Adults》 | 22 项，采用正常 / 轻度 / 中度 / 重度分区值 |

### 2. EF 计算

输入 4 个 M 型测量值（单位 mm）：**LVIDd、LVIDs、IVSd、LVPWd**

输出：

- **容积指标**：EDV、ESV、SV
- **收缩功能**：EF（含彩色分级进度条）、FS、RWT
- **左室质量**：LVM、LVM 指数（LVM/BSA）

### 3. 其他计算

血流动力学常用换算：连续方程、分流、Bernoulli 压差、跨瓣压差、右心相关指标等。

### 4. 节段划分

17 节段模型的交互式示意图，含各切面与室壁的对应关系。

### 5. 儿童 Z 值（0–18 岁）

儿童心脏随生长剧烈变化，**固定区间必然失真**（新生儿 LVEDD 2 cm 正常，成人 2 cm 是严重缩小）。
国际上把测值按体表面积标准化后算 **Z 值**：

- 输入身高体重 → 按 **Haycock 公式**算 BSA
- 填测量值（内径 mm / 容积 mL / 质量 g / 面积 cm²），常用 8 项快捷输入，展开可填全部 **33 项**
- 输出每项的 **Z 值 + 判定**，以及 **±2SD / ±3SD** 对应的实测区间
- 结果摘要：正常 / 轻度 / 显著 各几项，并指出偏离最大的项

**判定阈值**：|Z| ≤ 2 正常；2 < |Z| ≤ 3 轻度异常；|Z| > 3 显著异常。

> ⚠️ 本页**不区分性别**。PHN 研究结论：性别对 Z 值的影响统计上显著，但差异 < 5%，
> 低于测量者间变异，**临床上可忽略**。

## 二、计算公式

### 体表面积

```
Du Bois  ：BSA = 0.007184 × 身高^0.725 × 体重^0.425
Mosteller：BSA = √(身高 × 体重 ÷ 3600)
Haycock（儿科首选）
         ：BSA = 0.024265 × 身高^0.3964 × 体重^0.5378
```

### 左心功能（Teichholz 法，M 型单平面）

```
V  = 7 × D³ ÷ (2.4 + D)        D 单位 cm，V 单位 mL
EF = (EDV − ESV) ÷ EDV × 100%
FS = (LVIDd − LVIDs) ÷ LVIDd × 100%
```

### 左室质量（Devereux 公式）

```
LVM(g) = 0.8 × 1.04 × [(LVIDd + IVSd + LVPWd)³ − LVIDd³] + 0.6
RWT    = 2 × LVPWd ÷ LVEDD
```

> ⚠️ **精度约定**：LVM 先舍入到 1 位小数，再计算 LVM/BSA 指数。
> 这样「拿界面显示的数字手算」与「程序输出」完全一致，避免临床核对时产生困惑。

### 儿童 Z 值

```
Z = ( 实测值 ÷ BSA^α − Mean ) ÷ SD
```

其中 α / Mean / SD 是每个参数各自的回归系数。`Z = 0` 即人群均值；`|Z| ≤ 2` 覆盖约 95% 健康儿童。

**为什么不用年龄？** 心脏结构与 **BSA** 的相关性远强于年龄。PHN 用 3566 例验证过：
按 BSA 标准化后，年龄的额外影响在临床上可忽略。换句话说 ——
**同龄孩子体型差异大时，心脏大小差异主要由体型决定，而非年龄。**

## 三、数据来源

### 成人：中国标准

中华医学会超声医学分会《中国成年人超声心动图检查测量指南》（2016 年，95% 参考范围，37 项）。

### 成人：ASE 国际标准

ASE/EACVI 2015《Recommendations for Cardiac Chamber Quantification in Adults》，
采用正常 / 轻度 / 中度 / 重度分区值。

> **单位说明**：ASE 指南原文内径类参数以 **cm** 表示（如 LVEDD 男性正常 4.2–5.9 cm），
> 本工具界面统一用 **mm**，程序会自动换算（4.2–5.9 cm → 42–59 mm）。
> 容积、质量、百分数类单位一致，不做换算。

### 儿童：PHN 数据库

**Pediatric Heart Network（PHN）Normal Echocardiogram Database**

- 主文献：Lopez L, Colan S, et al. *Circ Cardiovasc Imaging.* 2017;10(11):e006979.
- 样本：**n = 3566**，0–18 岁健康非肥胖儿童，19 个中心，Core Lab 统一测量
- 系数表公开：<https://www.pediatricheartnetwork.org/forresearchers/echo-z-scores/>
- 同源前身：Pettersen MD, et al. *JASE* 2008;21(8):922-934
  （波士顿儿童医院 Z 值系统基于此）

LDESD / LVESV 两项系数来自后续补充发表
（*"PHN Echocardiographic Z-Scores: Comparison to Other Published Models"*, PMC7870534），
因其未包含在首发索引表中。

**交叉验证**：PHN 系数在成人 BSA（1.847 m²）下的推算值，与 ASE 成人指南吻合 ——
LVEDD ±2SD 推算 **4.26–6.00 cm**，ASE 给出 **4.2–5.9 cm**。
两者高度吻合，说明公式与系数自洽。

## 五、常见问题

**Q：儿童页为什么要填身高体重，不能直接填年龄吗？**

A：因为心脏大小与 **体表面积（BSA）** 的相关性远强于年龄。
同为 5 岁，一个 15 kg 一个 25 kg，心脏大小差异主要由体型决定。
PHN 已用 3566 例验证：按 BSA 标准化后，年龄的额外影响临床上可忽略。
年龄栏仅用于「超过 18 岁提醒你用成人标准」这一提示。

**Q：儿童页为什么不分性别？**

A：PHN 研究结论 —— 性别对 Z 值的影响统计上显著但 < 5%，低于测量者间变异（≥ 5%），
临床上可忽略。所以一套系数通用。

**Q：Z 值 2.5 算严重吗？**

A：|Z| 在 2–3 之间属**轻度异常**，3 以上才是**显著异常**。
但 Z 值只是判读工具之一，是否干预取决于结构类型、趋势变化和临床症状。

**Q：切到 ASE 标准后单位对不上？**

A：指南原文用 cm，界面用 mm，程序会自动换算。
如果参考区间显示成 `42.0–59.0 mm` 这样，就是对的。

**Q：手机上怎么用？**

A：直接用浏览器打开网页版即可：<https://heiqingyu.github.io/echo-ref/>
微信里可以「添加到桌面」当独立图标用。
